Security boundary

Local-only in this release. VPN enrollment and network changes are not automated. NetBird is read-only; REA is started only when enabled. Process startup is not proof of VPN security or MCP protocol readiness.

Do not expose this dashboard to the LAN or internet. Remote access requires a separate authentication, TLS, authorization, and threat-model release.
