Security boundary

Dashboard and APIs bind to loopback only. All functional AI, compute, and REA operations require NetBird plus the configured exit-node route. The controller stops managed services and rejects functional requests when that gate is lost.

This is application-level fail-closed gating, not a Windows Firewall kill switch. Full-device VPN-only egress still requires separately qualified firewall, IPv6, and DNS leak controls. NetBird owns WireGuard keys; Fun Industrial does not export them. Never paste setup keys or sensitive datasets into the dashboard.
