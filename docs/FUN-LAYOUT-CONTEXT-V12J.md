# V12J — Context-aware interpretation proposals (review-only)

V12J operates on V12I reconciliation evidence and V12A extracted page text. It selects material text disagreements, high-overlap cases, and same-text/different-grid cases, searches for bounded literal table-cell anchors in original page text, and collects nearby lines, possible captions, footnotes and unit mentions. It generates **review instructions and source-line references, not verified corrections**. This is a domain-independent heuristic; it does not understand multi-page table continuation, rotated text, visual coordinates, or actual document semantics. It may miss context if PDF text extraction reordered content. No model is called, no source is overwritten, and no CAD authority is granted.

The script checks V12I's SHA256 link to V12H, source PDF SHA stored in the V12A page manifest, and page indices. It does not rehash original PDFs (those were verified in V12H). Output is idempotent and fails on changed preexisting results.
